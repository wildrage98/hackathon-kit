# 07 — 약점 자가 진단 (제출 10분 전)

```
내 코드의 약점을 평가자처럼 찾아라. 고치지 마라. 각 항목은 "어디(파일:함수) / 어떤 입력에서 틀리나 / 운영상 영향 / 검증 또는 개선 방법" 네 칸으로.
대상:
1. 판단 로직의 경계 조건 (기준값과 같을 때, 첫 레코드, 상태 전환, 데이터 끝)
2. 데이터 품질 정책이 틀리는 경우 (중복인데 값이 다름, 끊김 후 복귀, 타임존 혼합)
3. 성능/확장 (데이터 10배, 설비 추가, 기준 변경 시 수정 범위)
4. 검증의 빈틈 (합성 데이터로만 확인한 것, 미검증 항목)
5. 외부 코드(kitlib) 의존 부분 중 내가 설명하기 어려운 곳
Top 5 만, 중요도순. 각 4줄 이내.
```
결과를 docs/DECISIONS.md 맨 아래 "## 자가 진단" 에 붙이고 읽는다.
