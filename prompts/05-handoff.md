# 05 — 세션 핸드오프 (컨텍스트가 길어졌거나 이전 지시를 잊기 시작하면)

현재 세션 마지막 프롬프트:
```
세션을 교체한다. 다음 세션이 이 파일만 읽고 이어서 할 수 있게 docs/HANDOFF.md 를 작성해라 (40줄 이내):
1. 완료된 것 (실행 명령과 로그 경로 포함)
2. 진행 중인 것과 현재 상태 (어느 파일 어느 함수, 무엇이 안 됨)
3. 확정된 기준·정책 (숫자 그대로)
4. 남은 작업 우선순위 (PLAN.md 기준)
5. 주의사항 (반복됐던 오류, 하지 말아야 할 것)
추측하지 말고 모르면 "확인 필요"라고 써라.
```
새 세션 첫 프롬프트:
```
AGENTS.md 와 docs/HANDOFF.md 를 읽고, 이어서 할 작업 1개를 "목표/제약/완료기준" 형식으로 제안해라. 코드는 내가 승인하면 쓴다.
```
