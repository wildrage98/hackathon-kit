# 04 — 검증 (130분 전후, 그리고 각 기능 직후 짧게)

```
구현된 기능을 검증해라. 통과 주장이 아니라 증거를 남기는 것이 목적이다.
1. 합성 데이터: `python -m kitlib.synth --out data/synth.csv` (또는 과제 데이터에 케이스를 심은 사본)로
   정답이 있는 입력을 만들고, 파이프라인을 돌려 kitlib.evalmetrics 로 P/R/F1(또는 일치 건수)을 계산해라.
2. 경계값 테스트를 tests/ 에 추가해라: 기준값과 같은 값, 첫 레코드, 상태 전환 직후, 값 누락, 중복 시각(값 다름), 시간 역전, N분 끊김 후 복귀.
   각 테스트 함수의 docstring 첫 줄에 "R<번호>: <요구사항>" 을 써라.
3. `tools/run_and_log.sh test python -m unittest discover -s tests -v` 로 실행하고 로그 경로를 보고해라.
4. docs/VERIFICATION.md 의 표를 채워라: 입력 / 기대 / 실제 / 판정 / 로그 경로. 실행하지 않은 항목은 "미검증"으로 남겨라.
통과하지 못한 테스트는 고치지 말고 먼저 보고해라. 고칠지 범위에서 뺄지는 내가 정한다.
```
