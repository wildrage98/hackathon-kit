# 02 — 계획 (확정 기준이 QUESTIONS.md 에 들어간 뒤)

```
$plan-verify 단계 1을 수행해라.
입력: docs/QUESTIONS.md 의 '확정 기준 메모', docs/AGREEMENT.md, playbook/<해당 유형>.md
출력: docs/PLAN.md 전체를 채워라. 특히
 - 7번 개발 순서는 4단계 이하, 각 단계의 완료 기준은 "실행 명령 + 기대 출력"으로
 - 1단계는 반드시 '최소 실행본'(입력→핵심 로직 1개→결과 파일) 이고 30분 안에 끝나야 한다
 - 8번 검증 계획에 심을 케이스 목록과 기대 결과를 적어라
 - 사용할 kitlib 모듈과 그 이유를 한 줄씩
확정 기준에 없는 것을 추측해서 채우지 마라. 빈칸은 "[담당자 확인 필요]"로 남겨라.
코드는 쓰지 마라. 내가 "계획 승인"이라고 할 때까지 기다린다.
```
승인 전에 내가 할 일: PLAN.md를 읽고 ① 필수 요구사항이 다 들어갔나 ② 1단계가 정말 30분짜리인가 ③ 검증 계획에 로그/숫자가 있나.
