# 00 — 세션 시작 (메인 세션 첫 프롬프트)

붙여넣기 대신 **타이핑 한 줄**로 충분하다 (Codex가 파일을 직접 읽는다 — 응시 환경은 클립보드가 불안정):
```
AGENTS.md 와 hackathon-kit/prompts/00-kickoff.md 를 읽고 그 안의 지시를 그대로 수행해.
```
이후 단계도 같은 방식: `hackathon-kit/prompts/02-plan.md 를 읽고 수행해` …

```
너는 이 과제의 구현 담당이다. 시간 관리와 모든 결정은 내가 한다. 아래를 먼저 수행하고 결과만 짧게 보고해라.

1. AGENTS.md 를 읽고 규칙을 3줄로 요약해라.
2. 과제 README(또는 안내 문서)를 읽고 다음을 표로 정리해라: 필수 제출물 / 실행 방식 / 입력 데이터 위치·형식 / 명시된 제약 / 모호한 점.
3. docs/QUESTIONS.md 를 열어 '확정 기준 메모' 표에 아직 비어 있는 항목 중 README로 답할 수 있는 것을 채우고, 못 채우는 것은 담당자에게 물을 질문 5개 이내로 뽑아라 (내가 직접 보낸다).
4. 코드는 아직 쓰지 마라. 계획(docs/PLAN.md)은 내가 "계획 시작"이라고 하면 $plan-verify 로 시작한다.

출력 형식: 1) 규칙 요약 3줄 2) 표 3) 질문 목록. 그 외 설명 생략.
```
