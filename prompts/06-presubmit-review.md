# 06 — 제출 전 교차 검토 (별도 검토 세션 또는 메인 세션, 제출 20분 전)

```
너는 이 프로젝트를 처음 보는 평가자다. 코드를 고치지 말고 검토만 해라.
1. README.md 의 실행 방법대로 **실제로 실행**해라 (tools/run_and_log.sh review <명령>). 안 되면 어디서 막히는지.
2. 요구사항(docs/AGREEMENT.md, PLAN.md 2번) 각각에 대해: 구현됨 / 부분 / 미구현 / 검증 로그 유무 를 표로.
3. docs/VERIFICATION.md 에 적힌 로그 경로가 실제로 존재하고 내용이 주장과 맞는지 확인해라.
4. 판단 근거가 출력에 포함되는지(값·기준·룰 이름) 결과 파일 한 줄을 인용해라.
5. 0.0.0.0 바인딩, PORT 환경변수, 비밀키 없음, requirements.txt 최신 — 확인.
6. README 에 빠진 것(입력 위치, 포트, 미구현 목록)을 지적해라.
출력: 표 1개 + 지적 사항 목록. 칭찬 생략.
```
그 다음 터미널에서 `python tools/preflight.py submit`.
