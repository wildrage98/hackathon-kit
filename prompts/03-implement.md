# 03 — 구현 (기능 하나 = 프롬프트 하나)

```
PLAN.md 7번의 [N]단계를 구현해라.
목표: <한 문장>
제약: stdlib + kitlib 만. 기준값은 config/ 에서 읽는다(하드코딩 금지). 기존 파일 구조 유지.
완료 기준: `tools/run_and_log.sh step<N> <실행 명령>` 이 exit 0 이고 <기대 출력>이 나온다.
끝나면: 1) 바뀐 파일 목록 2) 실행한 명령과 로그 경로 3) 결과 3줄 4) 이 코드가 틀릴 수 있는 입력 2개.
설명·주석 장황하게 쓰지 마라. 판단 로직에는 '왜' 주석 한 줄만.
```
끝난 뒤 내가 할 일 (매번, 2분):
- 로그 파일이 실제로 있는지 `ls logs/`
- 핵심 함수 1개를 직접 읽고 `$decision-log` 로 한 줄 기록 (임계치·정책·범위 결정)
- "틀릴 수 있는 입력 2개" 중 하나를 다음 04-verify 에 넣는다

막혔을 때 (같은 오류 2회):
```
같은 오류가 반복된다. 수정 시도를 멈추고 1) 오류의 원인 가설 3개 2) 각 가설을 확인할 명령 1개씩 만 써라. 코드 수정은 내가 고른 뒤에.
```
