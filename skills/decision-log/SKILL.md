# decision-log

사용자가 나중에 AI 없이 구두·서술로 설명해야 하는 것들을 `docs/DECISIONS.md`에 남긴다.

## 기록 시점
- 아키텍처·파일 구조를 정하거나 바꿀 때
- 임계치, 등급 기준, 지속 조건 등 **숫자**를 정할 때 (출처 포함: 담당자 답변 / 사용자 제안 / 임의 기본값)
- 데이터 품질 처리 정책을 정할 때
- 기능을 빼거나 줄일 때
- 사용자가 네 출력을 수정했을 때
- 네가 만든 코드 중 사용자가 아직 읽지 않은 부분이 생길 때 (→ "미검토"로 기록)

## 형식
해당 섹션(설계 / 판단 기준 / 데이터 품질 / 범위 조정 / AI 활용) 아래에 한 줄 추가:

`- [HH:MM] 결정 | 이유 | 버린 대안 | 한계·미검증`

시각은 `date '+%H:%M'`으로 얻는다. 추측하지 않는다.

## 규칙
- 한 결정에 한 줄. 설명은 25단어 이내.
- 이미 적힌 결정을 바꿨으면 새 줄로 추가하고 이전 줄 끝에 `(→ HH:MM 변경)`을 붙인다. 삭제하지 않는다.
- 기록 후 사용자에게 "DECISIONS.md에 N줄 추가"만 알린다. 내용을 되풀이하지 않는다.
