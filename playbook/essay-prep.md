# 확인 문제 대비

## 프레임 (5분 = 읽기 30초 + 쓰기 4분)
```
[결론 1줄]  "~는 ~방식으로 처리했고, 약점은 ~입니다."
[근거]      파일/함수, 값, 왜 그 선택
[약점+영향] 틀리는 상황과 운영상 결과
[검증/개선] 검증한 것(로그/테스트 이름) + 시간 있으면 할 것 1~2개
```
"모르겠다" X → "검증하지 못했다, 검증하려면 X".
